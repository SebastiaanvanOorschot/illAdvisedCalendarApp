# Agenda Frontend

Vue 3 + TypeScript frontend for the Agenda Calendar App. See the [root README](../README.md) for project overview, features, and setup instructions.

## Commands

```bash
yarn dev       # start dev server
yarn build     # type-check (vue-tsc) + production build
yarn preview   # preview the production build locally
yarn lint      # eslint --fix
yarn format    # prettier
```
